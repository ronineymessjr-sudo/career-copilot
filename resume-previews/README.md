# 任毅文｜真实简历结构化预览

这组预览已经从“项目摘要”改成真实求职简历结构：

1. 顶部先给出岗位定位和技术关键词；
2. 每个项目用“做了什么 + 怎么做 + 交付/验证结果”展开；
3. 工程版突出架构、接口、数据和测试；产品版突出问题拆解、用户流程和决策；解决方案版突出需求到交付的链路；通用版保留跨方向可迁移能力；
4. 只写仓库、部署文档和已验证项目证据能够支持的内容，不补虚构的用户量、收入、准确率或公司经历。

共同基础事实：

- Career Copilot：Next.js/React、Cloudflare OpenNext、Supabase/PostgreSQL/pgvector、LangGraph、MCP、GitHub Actions、Scheduler、异步队列和证据约束简历生成；
- PhotoAtelier Agent Lab：LangGraph 状态图、LangChain 结构化输出、RAG、FastAPI、Schema/摄影规则校验和人工审批写入；
- Camera Market Strategy System：FastAPI、SQLAlchemy、PostgreSQL/Supabase、Next.js、Docker/GHCR、Cloudflare、证据上传与可操作价格信号规则。

简历展示使用姓名和方向，联系方式在最终投递版中注入；本目录中的版本均不是已提交的外部投递。
