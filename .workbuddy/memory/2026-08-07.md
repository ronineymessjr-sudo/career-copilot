## Career Copilot V2 — Queue 架构实现 (M08.1 续)

### 背景
圣上要求实现异步队列系统，解决"用户搜一次岗位可能卡 10 秒"的体验问题。采用双路径消费架构。

### 新增文件 (commit 7134e7a)
1. **supabase/migrations/0025_async_queue_jobs.sql** — 核心表
   - `queue_jobs` 表（job_type: search/resume_generation/evaluation/dispatch）
   - `queue_results` 表
   - 5 个 RPC 函数：fetch_next_pending, claim_queue_job, complete_queue_job, fail_queue_job, recover_stale_jobs
   - RLS: owner 可读写自己行；service_role 全权（migration 0013 授权）

2. **apps/web/lib/queue-consumer.mjs** — 核心模块 (~245 行)
   - submitQueueJob / pollQueueJob / getQueueResult / consumeQueueJobs / tryProcessJob
   - search job 处理：discoverFromSource → adminDataRequest 直写 jobs 表（绕过 RLS）
   - 后续 job_type（resume_generation, evaluation, dispatch）预留占位

3. **4 个 API 路由**:
   - `/api/queue/submit` — POST，auth required
   - `/api/queue/poll` — GET，?job_id=xxx&try_process=true（fast-path）
   - `/api/queue/result` — GET，?job_id=xxx
   - `/api/queue/consume` — POST，cron-secret auth（slow-path）

4. **Scheduler Worker 更新**:
   - wrangler.jsonc: crons 新增 `"*/5 * * * *"`（每 5 分钟）
   - index.ts: 新增 queue-consume 分支，根据 cron 表达式分派路径
