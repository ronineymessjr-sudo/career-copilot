# Career Copilot V2 — Complete Platform

Career Copilot 是一个多用户岗位聚合、个性化推荐、简历匹配与投递辅助平台。当前交付是完整源码，不是增量补丁。

## 产品结构

- **今日简报**：岗位池、来源健康、推荐结果和待办概览。
- **岗位发现**：展示完整岗位池；用户画像只影响排序和解释，不会隐藏其他岗位。
- **岗位来源**：自动聚合 Greenhouse、Lever、Ashby 公开 ATS；其他平台通过真实 URL/JD 导入。
- **投递管理**：展示材料缺口、待投递和已完成记录；空状态会解释原因和下一步。
- **数据看板**：来源、匹配、投递与转化数据。
- **我的画像**：每个用户独立设置方向、地点、工作方式、毕业年份和可用时间。
- **简历版本 / 项目证据**：每个用户独立保存，不与其他账号共享。

## 多用户模型

平台共享岗位与用户私有岗位并存。所有登录用户可以读取共享岗位；私有导入、画像、评价、简历、证据和投递记录按账号隔离。同一个共享岗位会根据不同用户的画像得到不同推荐顺序、资格判断和简历匹配。

新账号使用中性画像，不预设 AI、2028 届、固定城市或“只看实习”。未填写画像时系统仍展示完整岗位池，并提示完善画像后开启个性化排序。

## 投递边界

系统可以完成岗位发现、排序、资格检查、简历匹配、材料缺口提示和投递入口准备。最终外部提交必须由用户明确确认；系统不会保存招聘平台密码、Cookie 或验证码，不绕过登录和反机器人验证，也不会把“打开页面”伪报成“已投递”。
