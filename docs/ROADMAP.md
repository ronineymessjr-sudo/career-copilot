# Roadmap

## Phase 1 — Product and workflow foundation — complete

- FastAPI API and SQLite local mode
- internship hard filters and match scoring
- evidence-driven application package generation
- approval-first workflow
- Next.js product shell and Supabase production schema

## Phase 2 — Engineering evidence — complete

- model gateway, health and metrics
- AI Coding delivery ledger
- Git/JUnit evidence collection
- GitHub Actions artifacts and benchmark ledger

## Phase 3 — Cloud data control plane — complete

- Supabase Auth and RLS
- authenticated Cloudflare Route Handlers
- Career Vault verification states
- stable job identity and user-owned application state
- approval, `ready_to_submit`, explicit `submitted` confirmation

## Phase 4 — Discovery and material operations — complete in Milestone 05

- Greenhouse and Lever public source adapters
- manual and daily Cron discovery
- source snapshots, dedupe and run history
- HR-verified field preservation
- Markdown, JSON, HTML/PDF and EML exports
- Gmail compose draft creation only
- live revalidation before export, draft and submission

## Phase 5 — Interview learning and measurement — complete in Milestone 06

- interview rounds, deterministic preparation and verified evidence stories
- structured question feedback and skill-gap queue
- explicit user confirmation for interview/Offer status changes
- channel, location and resume-version conversion analytics
- weekly review generation and weekly Cron
- operational health dashboard

## Phase 6 — Cited knowledge and durable approvals — complete in Milestone 07

- Career Vault text-document ingestion and deterministic chunk provenance
- pgvector storage and cited semantic retrieval
- deterministic lexical fallback when embeddings are unavailable
- Supabase-backed LangGraph checkpoints and human interrupts
- stale-source revalidation before evidence promotion

## Phase 7 — Grounded Agent execution — complete in Milestone 08

- LangGraph Supervisor and task-specific execution nodes
- user-owned Agent run, message, trace and evaluation ledger
- hybrid rule, semantic and historical job ranking
- hard-block recommendation caps and cited explanations
- verified-evidence resume personas and alignments
- authenticated MCP-compatible JSON-RPC tools
- approval-only consequential MCP operations
- RAG and grounding evaluation framework
- Agent dashboard and daily discovery/ranking/report cycle

## Phase 8 — Next priorities

- production migration, build and authenticated E2E evidence for version 1.0.0
- additional official job-source adapters with source-quality scoring
- statistically cautious resume experiment cohorts
- source freshness, evidence expiry and stale-score invalidation policies
- MCP client registration and revocable scoped tokens
- queue-backed long-running Agent jobs and retry/dead-letter handling
- deployment SLOs, alert routing and backup/restore drills

## Permanent safety boundary

- no CAPTCHA bypass
- no recruitment-platform credential collection
- no automatic email sending
- no unattended final submission
- no automatic interview or Offer acceptance
- no status marked `submitted` without explicit user confirmation
- no retrieved passage promoted to verified evidence without human approval
- no consequential MCP action without a separate application approval flow


## Phase 8 — Recruiter-facing portfolio experience — complete in Milestone 08.1

- public Agent Playground;
- four evidence-grounded resume personas;
- deterministic Agent Evaluation report;
- FastAPI portfolio endpoints;
- Docker demonstration stack;
- production build and public E2E remain deployment gates.
