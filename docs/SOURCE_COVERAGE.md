# 岗位来源覆盖与合规边界

## 自动聚合

### Greenhouse

- 使用公开 Job Board API。
- 以公司 board token 为标识。
- 读取已公开岗位、地点、正文和真实申请链接。

### Lever

- 使用公开 Postings API。
- 以公司 site name 为标识。
- 读取公开岗位、分类、工作地点、薪酬描述和申请链接。

### Ashby

- 使用公开 Job Posting API。
- 以公司 job board name 为标识。
- 读取公开岗位、地点、团队、雇佣类型、薪酬和申请链接。

## 链接与 JD 导入

以下来源在没有稳定、无需授权的公开读取接口时，通过用户提供的真实岗位链接和 JD 进入岗位池：

- 公司官网 / Workday
- BOSS 直聘
- LinkedIn Jobs
- 实习僧 / 牛客
- 智联 / 前程无忧 / 猎聘
- 邮件、内推和校招群

## 明确不做

- 不伪装成平台官方 API。
- 不绕过登录、验证码、设备验证或反机器人机制。
- 不抓取私人账号内容。
- 不保存招聘平台密码、Cookie 或验证码。
- 不在没有最终确认时提交申请或发送邮件。

## 平台运营方式

- 平台运营账号添加公开公司 ATS，并将 scope 设为 `shared`。
- Scheduler 定期刷新共享来源，岗位进入公共池。
- 普通用户可以添加 `private` 来源，只影响自己的岗位池。
- 普通用户可浏览共享岗位，并获得各自独立的推荐和资格判断。
