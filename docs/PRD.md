# Career Copilot V2 — PRD

## 产品定位
面向中国在校生的证据驱动 AI 求职操作系统。它不是海投机器人，而是把岗位发现、资格核验、匹配分析、简历定制、审批、投递记录、面试复盘和 Offer 管理放在一个可解释的工作台中。

## 核心用户
- 2028 届人工智能本科生
- 目标方向：AI Agent 应用研发、LLM/RAG、AI 产品、AI 解决方案、AI 运营与可迁移技术实习
- 地域顺序：远程 > 南通崇川 > 南京建邺/浦口 > 上海/苏州/杭州 > 其他补充
- 公司顺序：小厂/创业团队 > 中厂 > 大厂冲刺

## MVP 页面
1. 今日简报：新增、高匹配、待审批、已投递、面试与 Offer
2. 岗位发现：聚合、去重、硬过滤、分段排序、来源核验
3. 岗位详情：JD 任务、HR 显性要求、隐性偏好推断、匹配证据、缺口与风险
4. AI 简历：主简历、岗位定制版、证据引用、差异对比
5. 投递管理：待投、已准备、已投递、已读、沟通、笔试、面试、拒绝、Offer
6. 面试管理：轮次、问题、复盘、技能缺口和下一步行动
7. 数据洞察：渠道、地区、公司规模、简历版本的回复率和面试率
8. 设置：地域规则、公司规模、模型、数据源、审批边界

## 关键规则
- 不把校招正式岗、提前批正式岗或收费培训混入实习池
- 2028 届、每周至少 3 天、至少 3 个月是硬条件；缺失信息进入核验队列
- 推荐不等于已投递；只有用户确认或可靠邮件动作完成后才记录 submitted
- 生成材料只能引用 Career Vault 中的真实证据
- 平台投递默认停在人工确认前；邮件默认只生成草稿

## 成功指标
- 高匹配岗位核验通过率
- 定制材料准备时间
- 招呼语回复率
- 简历通过率、面试率、Offer 率
- 错误投递率与重复投递率保持为 0
